## Codebase Patterns
- This is a React + Vite app using react-router-dom v7 for routing
- All routes are defined in src/App.jsx inside a `<Routes>` block
- Page components live in src/pages/
- To add a new route: import the page component at top of App.jsx, then add `<Route path='...' element={<Component />} />` inside `<Routes>`
- Quality checks: `npm run lint` (eslint) and `npm run build` (vite build)
- No typecheck script; build serves as type validation for JSX
